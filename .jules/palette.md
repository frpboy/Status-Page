## 2025-05-18 - Accessible Visualizations & Switch Controls Pattern
**Learning:** Historical uptime micro-bars rendered as bare styled divs with mouse-only hover tooltips (`title`) are inaccessible to screen readers and keyboard users unless given explicit image/data semantics (`role="img"`, `tabIndex={0}`, matching `aria-label`, and `focus-visible` ring indicators). Similarly, text toggle buttons behaving like boolean state controls need `role="switch"` and `aria-checked` to communicate state clearly to assistive technologies.
**Action:** When creating or maintaining status and visualization widgets in this design system, pair `title` attributes on data elements with `role="img"`, `tabIndex={0}`, and `aria-label`, and ensure all interactive elements include visible keyboard focus styles (`focus-visible:outline-none focus-visible:ring-2`).
